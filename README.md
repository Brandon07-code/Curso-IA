## Descripción del Proyecto
PAVIA es una plataforma basada en Inteligencia Artificial y Visión por Computadora diseñada para la detección, clasificación y análisis del deterioro vial en el municipio de Cartago, Valle del Cauca, permitiendo a los ciudadanos reportar daños y evaluar riesgos en tiempo real.

## Tecnologías
- Python 3.12
- Docker & Docker Compose
- NumPy, Pandas, Matplotlib, Scikit-Learn
- Git & GitHub

## Ejecución del Entorno Docker

### Construir la imagen
```bash
docker compose build
```

### Ejecutar el contenedor
```bash
docker compose up
```

### Detener el entorno
```bash
docker compose down
```
